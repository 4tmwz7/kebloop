# Unicode emoji data

The emoji picker bundles Unicode Emoji 18.0's official `emoji-test.txt` file from
<https://unicode.org/Public/18.0.0/emoji/emoji-test.txt>. The snapshot is dated
2026-04-30 and is bundled for offline use. Kebloop reads only records marked
`fully-qualified`, which excludes unqualified duplicates and standalone
components such as skin-tone modifiers.

The Unicode License V3 notice is bundled beside the data at
`Sources/KebloopCore/Resources/unicode-license.txt`. Unicode's current terms
are available at <https://www.unicode.org/copyright.html>.
